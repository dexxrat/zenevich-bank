## 📖 Overview

**Zenevich Bank** is a complete **enterprise-grade microservices platform** built as a portfolio project to demonstrate **professional test automation skills**. This project showcases a full‑cycle development approach: from microservices architecture to a comprehensive test automation framework with CI/CD integration.

### 🎯 Why This Project?

This project demonstrates my ability to:
- ✅ Design and implement **microservices architecture** with Spring Boot
- ✅ Build a **professional test automation framework** from scratch
- ✅ Write **production‑ready tests** (API, UI, Database, Performance)
- ✅ Set up **CI/CD pipelines** with GitHub Actions
- ✅ Generate **Allure reports** for test visibility
- ✅ Containerize everything with **Docker & Docker Compose**
